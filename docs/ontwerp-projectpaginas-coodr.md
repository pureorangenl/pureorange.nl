# Ontwerp: projectpagina’s Coodr

**Project:** Aanpassing website PureOrange.nl  
**Fase:** Ontwerp · Ronde 1  
**Doel:** Vastleggen hoe project Coodr op de site wordt gepresenteerd, ter goedkeuring door belanghebbenden.

## 1. Scope

| Onderdeel | In scope |
|-----------|----------|
| Homepage | Teaser voor Coodr in de projecten-/oplossingensectie |
| Detailpagina | Eigen pagina die Coodr toelicht |
| Navigatie | Link van teaser naar detailpagina; terug naar homepage |

Buiten scope: implementatie, contentproductie (definitieve copy/beeld), SEO-techniek, externe product-URL’s behalve vermelding.

## 2. Informatiearchitectuur

```
Homepage (/)
  └─ Sectie Oplossingen / Projecten
       ├─ Candidakuur (bestaand)
       └─ Coodr → /projecten/coodr (of /oplossingen/coodr)
```

Eén detailpagina volstaat. Geen apart overzicht van alle projecten in deze ronde.

## 3. Homepage-teaser

Plaats Coodr naast Candidakuur in dezelfde sectie, met hetzelfde patroon:

- **Titel:** Coodr  
- **Korte zin:** waar het product voor dient (1–2 zinnen)  
- **CTA:** link naar de detailpagina (niet alleen een externe URL)

Visueel: bestaande solution-card-stijl hergebruiken (geen nieuwe card-variant).

## 4. Detailpagina Coodr

Opbouw, van boven naar beneden:

1. **Header** — PureOrange-logo, link terug naar homepage  
2. **Intro** — eyebrow “Project” / “Oplossing”, titel “Coodr”, korte lede  
3. **Wat het is** — probleem/oplossing in één korte sectie  
4. **Kernpunten** — 3 à 4 bullets (bijv. voor wie, wat het doet, resultaat)  
5. **Optioneel** — link naar product of demo, indien beschikbaar  
6. **Footer** — gelijk aan homepage

Geen aparte contactsectie op de detailpagina; contact blijft op de homepage.

## 5. Visuele aansluiting

- Kleuren, typografie en spacing volgen de bestaande PureOrange-stijl (`--orange`, `--ink`, `--paper`, Inter).  
- Zelfde max-breedte en rustige layout als de homepage; geen dashboard-achtige grid.  
- Beeld alleen als het product of context toont; geen decoratieve collage.

## 6. Acceptatie

Het ontwerp is geaccepteerd wanneer belanghebbenden akkoord gaan met:

- de teaser op de homepage naast bestaande oplossingen;  
- één detailpagina met de opbouw hierboven;  
- hergebruik van de huidige huisstijl zonder nieuwe componenttaal.

Na goedkeuring volgt de realisatiefase.
